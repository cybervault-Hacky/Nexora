## 4. New verification: Rust ↔ TypeScript contract

`apps/desktop/ui/src/lib/rustContract.test.ts` reads the real Rust and TypeScript sources at test time and compares the serialised contract. Every other UI test replaces the IPC boundary with a double, so a field or argument rename would pass those tests and fail only in the packaged app.

It checks:

1. **Struct field names** — for `AppStatus`, `EngineStatus`, `ChatTurn`, `GenerateRequest`, `GenerationOutcome`, `ModelInfo`, `RuntimeInfo`, `SystemInfo`, `Settings`, and `InferenceError`, the test parses each Rust `pub struct`, applies its `#[serde(rename_all = ...)]` and field-level `#[serde(rename = ...)]` attributes, and requires the resulting wire names to equal the TypeScript interface fields.
2. **`EngineState`** — requires `rename_all = "snake_case"` and compares every serde-renamed variant with the TypeScript union (`not_configured`, `stopped`, `loading`, `ready`, `generating`, `error`).
3. **`GenerationEvent`** — requires the internal tag `type` and `rename_all = "snake_case"`; requires the variants to serialise as `started` and `delta`; requires the payload fields (`requestId`, `text`) to be exactly the TypeScript fields other than the tag.
4. **Pinned wire shapes** — explicit expectations for the names above, so a *coordinated* rename on both sides cannot silently redefine the contract.
5. **Command registration** — the ten `#[tauri::command]` functions in `inference/commands.rs` must equal the ten entries in `generate_handler![...]` in `lib.rs`, with no duplicates on either side.
6. **Command invocation** — the commands called from `ui/src/lib/inference.ts` (through `call()`/`invoke()`) must equal the registered set. A UI calling a command that does not exist, or a command never wired to the UI, fails.
7. **Argument keys** — for every command, the keys the UI sends must equal the camelCase form of the non-injected Rust parameters (`State` and `AppHandle` excluded), and every command must keep the default `#[tauri::command]` attribute that makes Tauri perform that camelCase conversion. This covers `start_generation` (`request`, `onEvent`), `cancel_generation` (`requestId`), and `validate_model` (`path`, `contextSize`).

### Sensitivity check (mutation test)

To prove the checks fail on real drift, two deliberate source mutations were applied, the contract test was run, and both mutations were reverted with `git checkout`:

| Mutation | Result |
|---|---|
| `AppStatus` changed from `rename_all = "camelCase"` to `"snake_case"` | `serialises AppStatus…` and `pins the wire shapes…` failed |
| `cancel_generation` parameter `request_id` renamed to `request_key` | `pins the argument names…` and `sends each argument…` failed |

**4 of 18 tests failed, as expected.** After reverting, the full suite returned to 105 / 105. An earlier mutation attempt on `EngineStatus` did *not* fail because all four of its field names are single words; `AppStatus` was used instead precisely because its `modelPath`, `runtimePath`, and `contextSize` names change under the wrong rename.

### Limits of this check

- It parses source text; it does **not** execute serde or Tauri. Attribute handling covers `rename_all` and field-level `rename`, not every serde feature (e.g. `flatten`, custom serialisers, numeric encodings, `Option` omission).
- It cannot catch Tauri/WebView2 runtime serialisation behaviour, version-specific argument conversion, or channel delivery.
- It reads `process.cwd()`-relative source paths, so it only runs inside the repository.
- A passing contract test is **not** a substitute for `cargo test` or a native run.
