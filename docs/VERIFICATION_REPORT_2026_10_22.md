## 2. Genuine Defects Uncovered & Resolved During Release-Candidate Audit

1. **Cross-Crate Wire Contract Mismatches (`apps/desktop/src-tauri` <-> `services/nexora-auth`)**:
   - `GET /v1/plans`, `GET /v1/billing/subscription`, `POST /v1/billing/checkout`, `GET /v1/usage`, and `POST /v1/usage/reserve` had JSON field differences (`displayName` vs `name`, array vs map `modelQuotas`, missing `portalAvailable` / `canceledAt`, `providerSessionId` / `expiresNote`, `periodDayUtc` / `resetsAtUtc`, `remainingAfter` / `replayed`) that caused `parse_error` when `AuthApiClient` hit a live `nexora-auth` process over TCP. Fixed cleanly across `services/nexora-auth/src/{billing,quota}.rs` and `apps/desktop/src-tauri/src/auth/mod.rs` and proven over a live TCP socket (`live_desktop_client_roundtrip_over_tcp`).
2. **Desktop Profile ID vs Server Quota Model ID Rejection (`400 unknown_model`)**:
   - `apps/desktop/src-tauri/src/inference/commands.rs` sends `selected.id` (`nexora-mini-qwen2.5-coder-7b-instruct-q4-k-m` / `nexora-sonnet-qwen2.5-coder-14b-instruct-q4-k-m`), whereas `plan_model_quotas` stores `nexora-mini` / `nexora-sonnet`. Added `quota::canonical_model_id()` in `services/nexora-auth/src/quota.rs` and verified end-to-end over TCP against PostgreSQL 16.
3. **Production Placeholder Guard (`REPLACE_WITH_*` & `nexora.local`) + `.env.example` Env Name Parity**:
   - Aligned every variable name in `.env.example` 1-to-1 with `services/nexora-auth/src/{config,billing}.rs` and hardened `AuthConfig::contains_placeholder()` to reject `replace_with` and `nexora.local` in `NEXORA_ENV=production` (verified both by `dot_env_example_is_complete_placeholder_only_and_fails_fast_in_production` and by running `./services/nexora-auth/target/debug/nexora-auth` directly, confirming exit code `2` with redacted output).
4. **Unpaid Checkout Order Verification UX (`PlansPage.tsx`)**:
   - Previously displayed a green success banner even if an order remained `"pending"` after verification. Updated `PlansPage.tsx` + `PlansPage.test.tsx` to check `matchedOrder?.status === "completed"` and report honest pending status when unpaid while keeping plan at `Free`.
5. **Per-Model Server Quota Exhaustion Banner & Consistent `00:00 UTC` Reset (`ChatPage.tsx`, `auth/commands.rs`)**:
   - Enforced selected-model server quota exhaustion in `ChatPage.tsx` with a clear plan/model/`00:00 UTC` message and replaced `"Next local midnight"` in `usage_get_server_summary` offline fallback with `crate::usage::format_utc_instant(snap.reset_at_ms)` (`YYYY-MM-DD 00:00 UTC`).
6. **Concurrent Burst Test Determinism (`tests/plans_billing_quota_db.rs`) & Extended Windows Smoke Script (`scripts/windows/smoke-verify.ps1`, `.github/workflows/ci.yml`)**:
   - Eliminated a task-scheduling race assumption in `concurrent_quota_reservations_release_on_failure_and_account_privacy_controls` and extended `smoke-verify.ps1` + `.github/workflows/ci.yml` (`windows-2022`) to validate WebView2 presence, Authenticode status, clean install, launch + shutdown + restart stability, over-top upgrade reinstall, and clean uninstall.
